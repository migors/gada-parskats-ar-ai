# Oficiālie avoti

Atver avota tekstu un pārbaudi, kura redakcija piemērojama konkrētajam periodam (likumi.lv redakciju var izvēlēt pēc datuma). Aģentam prasi atsauci uz konkrētu pantu un redakciju. Šis saraksts nav tiesību normu kopsavilkums.

| Avots | Saite |
| --- | --- |
| Grāmatvedības likums | https://likumi.lv/ta/id/324249-gramatvedibas-likums |
| Gada pārskatu un konsolidēto gada pārskatu likums | https://likumi.lv/ta/id/277779-gada-parskatu-un-konsolideto-gada-parskatu-likums |
| Uzņēmumu ienākuma nodokļa likums | https://likumi.lv/ta/id/292700 |
| VID Elektroniskā deklarēšanas sistēma | https://eds.vid.gov.lv |
| VID mājaslapa | https://www.vid.gov.lv |

Ja uzņēmumam ir darbinieki, PVN vai citi nodokļi, aģentam palūdz noskaidrot attiecīgos papildu avotus.
