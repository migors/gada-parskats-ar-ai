# Starta komplekts: gada pārskats ar AI

Bezmaksas veidnes darbam ar AI aģentu, kas strādā ar failiem un pārlūku (piemēram, Claude Code). Paredzēts nelielai SIA, kur vadītājs drīkst kārtot grāmatvedību pats. Šī nav nodokļu vai juridiska konsultācija; par grāmatvedību atbild uzņēmuma vadītājs.

Veidnes nesatur uzņēmuma datus, gatavas deklarācijas vai automātiskas iesniegšanas programmas.

## Kā sākt

**Ātrais ceļš (Claude Code):**

1. Izpako komplektu jaunā mapē.
2. Atver šo mapi Claude Code.
3. Uzraksti: `Sākam gada pārskatu` (vai `/gada-parskats`).

Skill pats izveidos mapju struktūru un darba failus, pateiks, kur ielikt dokumentus, nointervēs tevi pa vienam jautājumam un vadīs cauri visiem soļiem līdz iesniegšanai EDS. Iesniegs tikai pēc tava "jā".

**Citiem AI rīkiem:** atver mapi un palūdz aģentam izlasīt `AGENTS.md` un `CELVEDIS.md` un rīkoties pēc tiem.

**Soli pa solim pats:** izmanto uzdevumus no `PROMPTI.md` secīgi.

## Faili

| Fails | Saturs |
| --- | --- |
| `AGENTS.md` | Darba noteikumi un atļauju robežas |
| `.claude/skills/gada-parskats/SKILL.md` | Skill: vednis, kas izveido mapes, intervē un vada cauri visam procesam (mape `.claude` var būt slēpta) |
| `CELVEDIS.md` | Tas pats vednis teksta veidā citiem AI rīkiem |
| `PROMPTI.md` | Kopējami prompti pa posmiem |
| `LIKUMI.md` | Oficiālie avoti |
| `PLAN.md`, `TODO.md`, `WORKLOG.md`, `APPROVALS.md` | Plāns, uzdevumi, žurnāls, atļaujas |
| `zinasanu-baze/FAKTI.md` | Fakti, avoti, statusi, neatrisinātie jautājumi |

Teksta noteikumi neaizstāj rīka piekļuves un apstiprinājumu iestatījumus: neatgriezeniskām darbībām ierobežo arī tos.
